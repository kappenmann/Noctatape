# NoctaTape – Tape Saturation Plugin (VST3)

Thank you for trying **NoctaTape** by Noctalune Audio.

NoctaTape is a tape-style saturation plugin designed to add warmth, character, and subtle movement to your sound.

---

## Requirements

* Windows (64-bit)
* A DAW that supports **VST3 plugins**

---

## Installation (Windows)

1. Copy the file **"NoctaTape.vst3"**
2. Paste it into the following folder:

```
C:\Program Files\Common Files\VST3
```

3. Restart your DAW
4. Search for **"NoctaTape"** in your plugin list

---

## Important Note

This plugin currently does **not include an installer**.

Windows may show a warning when downloading or opening the file.
This is normal for new indie plugins without code signing.

---

## Usage

* Insert NoctaTape on any track or bus
* Adjust the parameters to taste
* Try different settings on:

  * Drums
  * Guitar
  * Full mixes

---

## Tips

* Use low settings for subtle warmth
* Push the input/drive for more saturation and character
* Works great on buses for glue and cohesion
